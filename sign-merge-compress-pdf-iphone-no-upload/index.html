Sign, merge and compress a PDF on iPhone

Keep your original documents. Combine only the pages you need, make any visual edits on a copy, and inspect the result before sending. PDF compression can change document features, so digitally signed or fillable files need particular care.

Plan the output before editing

Check the recipient's page order, size limit and signature requirements. A typed or drawn signature is a visible mark; it is not the same as preserving an existing cryptographic digital signature. Follow the requirements for the document you are sending.

Use a separate working copy

Our App, PDF Compressor: Sign & Merge, lists merging, page reordering, drawn or typed signatures, watermarks and compression in its current published version. Use the available document tools on a working copy and keep the originals separate.

Compress only after checking what must be preserved

The current App listing explains that compression may create image-backed PDF pages and remove selectable text, forms, links, annotations, metadata or layers. If those features are required, do not assume a smaller PDF retains them. Keep the original and choose an appropriate output workflow.

Inspect the exported file

Open the exported PDF. Check page order and count, small text, any visible signature, links and fields that the recipient requires. Confirm the actual file size and try the intended upload or mail workflow before deleting a source copy.

Common questions

Does compression preserve forms and selectable text?

Not necessarily. The current App listing warns that compression can create image-backed pages and remove document features.

Is the browser output identical to the iPhone App output?

No. They are different tools. Our browser PDF exports include a small app logo watermark; inspect the actual output from the tool you use.
