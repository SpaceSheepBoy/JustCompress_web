Follow these steps

  1. Open Video Compressor and select the video you want to make smaller.
  2. Choose compression settings appropriate for the destination and preview where available.
  3. Export the compressed copy without deleting the original.
  4. Check file size, image quality, sound and duration, then share the exported file.

Find out what the destination accepts

A smaller video is useful only if the receiving app can use it. Read the destination’s current file-size, format and duration rules. If it requires H.264 MP4, lowering the file size alone may not solve a codec issue. Use the HEVC conversion guide for that specific problem.

Start with a moderate setting

Compression trades file size against visual detail. Fast motion, foliage, screen text and low-light scenes are useful places to inspect the result. Make one test export before compressing a collection. Do not assume every video will achieve the reduction shown in a tutorial example.

Keep originals until you have checked the copy

Compression produces a sharing copy. Preserve the original for future editing and compare both at a useful viewing size. If the compressed version is hard to read or shows distracting artifacts, use a higher-quality setting and check the new result.

Prefer a browser tool for a short one-off job

The free Just Compress video tool processes supported clips in your browser. Large or long clips can exceed the memory available to a browser tab, especially on a phone. For an iPhone workflow, use the native app and review its current purchase options on the App Store.

Common questions

Will ZIP make my video much smaller?

Already compressed video often gains little from ZIP. Re-encoding or a lower-resolution sharing copy is usually a more relevant workflow.

Does compression fix washed-out HDR color?

Not necessarily. If the destination mishandles HDR, use an explicit HDR-to-SDR conversion and inspect the output.
