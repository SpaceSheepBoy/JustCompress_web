Photo Print Came Out the Wrong Size? Measure a Proof

If a photo prints at the wrong physical size, print a proof at 100% and measure its reference ruler before changing DPI again. Correct file metadata cannot prevent a printer or print dialog from scaling the page.

Choose the approach

File size and paper size differ

Pixels and DPI define a nominal image size. The viewer or printer can still fit, shrink or expand that image. Confirm the intended paper size, image dimensions and orientation, then examine the controls in the actual print workflow.

Try it on iPhone

  1. Prepare the intended print size in DPI: Photo Print Prep and review the export’s pixels, both DPI axes and physical dimensions.
  2. Create the app’s 4 × 6 inch PDF proof with its 100 mm ruler. Print at 100% or Actual Size rather than Fit.
  3. Measure the printed ruler with a physical ruler. If it is wrong, check paper-size and scaling settings before judging the photo crop.

Use the proof as a check

A selectable 1:1 detail helps examine a small region, but the screen illustration is not a calibration tool. Printer feed and driver behavior can still affect physical output. Keep the proof settings with the final job so the verified workflow is reproducible.
