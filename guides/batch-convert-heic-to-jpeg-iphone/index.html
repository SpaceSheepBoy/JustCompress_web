Quick check

Test a few files first

Start with two or three photos that you can easily tell apart. Include one with fine detail. Save the test copies together so you can compare them with the original selection.

Try it on iPhone

  1. Select the HEIC photos in PhotoFix and choose JPEG output. Review the options for the capture date and location.
  2. Check file details to confirm JPEG. Match the number and subject of the exported files to the originals.
  3. Send the checked JPEG copies and keep the HEIC files for future exports.

Check dates in the saved copies

Preserve the capture date if the receiving library needs it. A file browser can instead sort by the time of export. Open one saved example in the destination to see how that library sorts it.
