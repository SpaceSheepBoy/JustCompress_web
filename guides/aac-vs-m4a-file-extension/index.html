AAC Export Became M4A? Check the Codec and Container

An AAC export can correctly have an .m4a extension. AAC describes the encoded audio, while M4A identifies an audio-oriented MPEG-4 container. The extension alone does not prove which codec is inside.

Choose the approach

Make the first check

If you asked for AAC and received M4A, first check the audio information in a trusted player or editor. Do not rename the file merely to make the letters match: a filename change does not convert the contents.

Try it on iPhone

  1. Check what the recipient actually requires: AAC audio in M4A, an MP3 file, or a specific raw AAC stream. These are different requirements.
  2. For an ordinary sharing copy, use the available conversion format in Audio Compressor MP3 Converter. Keep the source and export a separate file.
  3. Open the saved copy in the receiving app. Confirm playback, duration and the reported encoding. If a specialist system demands raw AAC, do not assume that an M4A export meets that requirement.

One extension, more than one codec

The UK National Archives identifies AAC-based M4A and notes that the extension is also used by Apple Lossless files. An M4A name therefore does not establish whether the audio is lossy. Likewise, selecting another container does not restore detail that an earlier lossy encode discarded.

Limits and final checks

This guide does not promise raw AAC/ADTS export or a lossless rewrap option. If the existing file plays correctly and the recipient accepts it, another conversion may be unnecessary. When MP3 is explicitly required, use a real MP3 conversion and check that new file rather than renaming the M4A.
