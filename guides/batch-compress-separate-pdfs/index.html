Compress Several PDFs While Keeping Each Document Separate

Use batch compression when several PDFs must stay separate. Merging creates one document; batch compression is the appropriate workflow when each original needs its own smaller delivery copy.

Choose the approach

Make the first check

Start with a small representative group, especially if some files contain scans and others contain mostly text. Similar filenames do not mean the documents will shrink by the same amount.

Try it on iPhone

  1. Keep the originals together in a source folder. Note how many PDFs you selected and identify any signed or certified files that need a different approved workflow.
  2. Use batch compression in PDF Compressor: Sign & Merge, then save the output copies. Choose the batch tool rather than Merge when separate files are required.
  3. Check that every expected document has an output. Compare page counts and sizes for each pair, then inspect small text, images and the first and last page.

Review files individually

One unreadable document should not be hidden by a successful result elsewhere in the group. If a particular output is missing or unsuitable, keep that original and handle it separately. Do not repeatedly compress the whole group merely because one file remains too large.

Limits and final checks

It does not establish a maximum batch size or a fixed reduction percentage here. Adobe’s PDF guidance also treats reduced-size output as a new copy, so retain your sources while checking quality. Before sending, confirm the recipient accepts several files and verify the exact attachments.

Limits and final checks

A ZIP may help package them, but it does not replace the document-level checks or prove that each PDF meets a size limit.
