Quick check

Choose where the story starts

Start with the first message that gives enough context. Stop after the exchange the recipient needs. If the thread changes subjects, two short images can be easier to read than one long image.

Try it on iPhone

  1. Take screenshots from top to bottom. Include one message of overlap before cropping.
  2. Crop private notifications, contact details and unrelated replies before you import.
  3. Stitch the screenshots vertically in Combine Photos: Stitch & Grid. Inspect the seams and open the saved image in Photos or Files.

Check the image after sending

Some chat apps compress long images. If the recipient cannot read individual messages at a useful zoom, share smaller sections or send the stitched image as a file where that option is available.

Common questions

Can I take a full-page screenshot?

Some iPhone views support full-page capture. Use separate screenshots if the conversation view offers no full-page option.

Does the image preserve every message?

It shows what you captured. Keep the thread if you need the full record.
