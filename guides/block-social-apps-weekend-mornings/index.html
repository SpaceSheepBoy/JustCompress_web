Block Social Apps on Weekend Mornings on iPhone

Create a recurring rule for Saturday and Sunday only. Select the social apps you want to pause and set a clear start and end time.

Quick check

Pick a block that fits your weekend

If you want breakfast or the first hour of Saturday to stay free from scrolling, start with that window. Leave calls and any other essentials available.

Try it on iPhone

  1. Open Dying Soon: Screen Time Limit, grant Screen Time access and select the social apps you want to pause.
  2. Create a recurring schedule and choose Saturday and Sunday. For example, set 8 a.m. to 10 a.m. on those days. Review the days and the time before saving.
  3. Test a selected app while the rule is active and after it ends. Check the weekday selection if you can still see the block on Monday.

Keep rules easy to check

One scheduled rule is available on the free plan. If you want a distinct weekday routine as well, Pro supports multiple schedules. Check which rule is active before changing or removing one.

Decide what should stay reachable

Leave any route for urgent contact out of your selection. If you use the social service through a browser, blocking its app does not cover that route. Open the actual app you want to test.

Common questions

Can I make it run on Saturday only?

Choose Saturday as the scheduled day and check that Sunday is unselected.

Can I test it before the weekend?

Review the selected apps and schedule immediately. Check the rule itself during the first planned weekend slot.
