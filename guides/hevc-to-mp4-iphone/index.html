Follow these steps

  1. Check the destination requirements and confirm that it needs H.264 video in an MP4 file.
  2. Open VideoFix, select the clip, and choose Convert HDR to SDR. This option also converts SDR HEVC input to H.264 MP4.
  3. Set an output resolution and optional maximum file size appropriate for the destination.
  4. Convert, save the MP4, and test that exported file in the destination.

MP4 is not the same thing as H.264

MP4 is a container. It can hold different video codecs, including HEVC, so a file ending in .mp4 is not automatically compatible with an H.264-only service. HEVC is also called H.265. For this workflow you need an actual re-encode to H.264, not a renamed file or a container-only change.

Read the upload error first

An upload may fail because of file size, duration, dimensions, connection problems, permissions or an unsupported codec. Do not assume every failure is caused by HEVC. Follow the service’s stated requirements. If it needs a smaller file as well as H.264, adjust resolution and the optional size limit before exporting.

What happens to HDR footage

If the input is HDR, VideoFix also maps it to Rec.709 SDR color. If the input is already SDR HEVC, the same option produces an H.264 MP4 compatibility copy. This process re-encodes the video, so keep the original when you need maximum editing quality.

Verify one file before converting more

Play the exported file, check the sound and duration, then try the real upload. A converted codec cannot resolve a login error or a file-size rule by itself. VideoFix includes three free conversions; later conversions require a paid plan.

Common questions

Can I just rename .mov to .mp4?

No. Renaming changes neither the container structure nor the encoded video.

Can HEVC footage already be SDR?

Yes. Codec and dynamic range are separate properties. VideoFix supports the HEVC-to-H.264 workflow for SDR input too.
