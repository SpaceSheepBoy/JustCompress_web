How to Use iPhone HDR Clips in an SDR Timeline

For an SDR edit, tone-map the HDR clips once. Let a color-managed editor do it, or convert those clips to Rec.709 before import.

Quick check

Choose where the color conversion happens

An HDR phone clip and an SDR camera clip can sit side by side in an SDR timeline. Treat each file according to its source color and preview both before cutting.

Try it on iPhone

  1. Confirm the project is intended for SDR. Keep the HDR originals for future edits or delivery.
  2. If the editor handles HDR input in an SDR sequence, use its input color management. Check one representative clip with skin tones and bright highlights.
  3. For an editor that does not handle the source predictably, use Convert HDR to SDR in VideoFix: HDR Video Converter. Import that Rec.709 H.264 MP4 and check that the editor treats it as SDR.

Avoid mapping the same clip twice

A converted SDR copy is already tone-mapped. Applying an HDR-to-SDR effect again can change its contrast. In an app that supports input color space settings, check that the source and the converted copy each use the correct interpretation.

Check an export before you commit to a batch

Export a short section containing both sources and play it back on the intended device. Compare faces and bright areas against your editor preview. Keep the original filenames distinct from the converted copies.

Common questions

Should I convert the clips that are already SDR?

Their color does not need HDR-to-SDR mapping. Leave them as they are if the editor already plays them correctly.

Does this workflow preserve HDR delivery?

It creates SDR copies for the SDR timeline. Keep the HDR originals if you also need an HDR version.
