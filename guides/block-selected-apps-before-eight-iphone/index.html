Block Selected iPhone Apps Until 8 a.m.

Use a recurring rule with a fixed morning start and end to block only the apps you select. Set the end to 8 a.m. if that is when you want access again.

Quick check

Use a clock window

A daily usage allowance counts minutes. A morning schedule uses set times. If the problem starts when you first pick up the phone, choose a start time earlier than that pickup.

Try it on iPhone

  1. Write down the apps you want to avoid before 8 a.m. Keep your alarm, calls, maps and any other essentials outside the list.
  2. In Dying Soon: Screen Time Limit, grant the requested Screen Time access and select the distracting apps. Set a recurring rule for the chosen morning hours. Check the selected days before you save it.
  3. Test a temporary window during the day first. Try one selected app and one essential app. Then check that the selected app opens again when the window ends.

If your wake time changes

The rule uses a clock and the days you set. It does not know when you woke up. For a one-off session, Block Now runs for 30 minutes. If your routine varies by day, check each scheduled window separately.

Set a manageable first rule

Space Sheep Studio develops Dying Soon for iPhone. One scheduled rule is free. Temporary unlocks of 5, 15 or 30 minutes are available. Start with the small list that causes the problem. If you also want to block the same apps at night, check what happens around midnight and when the morning rule ends.
