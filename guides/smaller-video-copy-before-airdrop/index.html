Make a Smaller Video Copy Before AirDrop

Compress a separate viewing copy first, then AirDrop that file. Keep the original for editing or delivery when the recipient needs full quality.

Quick check

Decide which copy the recipient needs

The copy you send should match the task. A smaller preview can be enough for a quick review. A project handoff may need the original resolution, frame rate and detail.

Try it on iPhone

  1. Open the video in Phone Cleaner: Photo & Video and choose a smaller output preset. Keep the original in Photos.
  2. Save the export and compare the file sizes. Check sharpness, motion and sound, especially where the video contains small writing or fast movement.
  3. Share that specific export by AirDrop. Ask the recipient to open it and confirm it is the expected clip before you remove any files.

Use file size to check the result

A different filename or container does not say how much data the file contains. Read the saved copy’s size. If the clip is still too large for your purpose, try a smaller quality preset on a fresh copy from the original.

Check the connection separately

Keep the devices near each other and confirm the recipient can receive via AirDrop. If a small known-good file also fails, troubleshoot discovery or use a cable for the original. Compression does not change AirDrop settings.

Common questions

Is there a universal size to aim for?

Choose a size that suits the recipient’s use and the detail they need. Compare the actual files.

Should I compress a video for an editor?

Ask the editor which source properties they need. Keep the original available.
