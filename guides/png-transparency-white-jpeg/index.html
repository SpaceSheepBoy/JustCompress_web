Why Did a Transparent PNG Turn White After JPEG Export?

A transparent PNG can turn white when exported as JPEG because JPEG does not retain an alpha transparency channel. Return to the transparent original and choose PNG when the destination needs to show its own background through the image.

Choose the approach

Preview color is not file evidence

A white viewer background does not prove that transparency is gone. Inspect the actual file type and place the image over another color in a tool that supports transparency. White pixels baked into a JPEG differ from transparent pixels displayed over white.

Try it on iPhone

  1. Open the transparent original in PhotoFix: HDR to Normal Photos and select a supported PNG output.
  2. Export a separate copy. Preserve the original while checking the saved file type and transparency.
  3. Test the file in the actual design or receiving app over a contrasting background. Share that verified PNG rather than an older JPEG copy.

Conversion cannot restore an alpha channel

Converting a white-backed JPEG to PNG changes the format, but does not automatically identify and remove the white background. Background removal is a separate editing task; PhotoFix is not claimed as a background-removal tool here.
