Does a 1200 DPI Printer Need a 1200 PPI Photo?

Use the file resolution specified by the lab or printer workflow. A printer’s ink-dot rating does not set the pixel density of the photo file.

Quick check

Start with the lab’s input requirement

If the lab asks for a 4 × 6 inch file at 300 pixels per inch, prepare a crop with 1200 × 1800 pixels. A printer can use multiple ink dots to represent colors. Its advertised dot count measures the output device, while PPI measures the image at the final size.

Try it on iPhone

  1. Set the intended paper size and the lab’s requested resolution in DPI: Photo Print Prep.
  2. Check the pixel count after cropping. Keep the pixels if the file already meets the requirements. Read back the actual dimensions of the export.
  3. If the source is too small, ask whether the lab accepts fewer pixels per inch or choose a smaller print. Resampling can satisfy a size rule but cannot add captured detail.

Check the lab preview

A lab can crop to fill the paper or add borders to fit the whole photo. Confirm the crop in the order preview and recalculate available pixels if the lab trims beyond your planned crop.

Common questions

Why does my lab call it 300 DPI?

Many services use DPI informally for file resolution. Check whether the instruction refers to the image file or the printer.

Does a larger DPI tag make a print sharper?

At a fixed print size, the available pixels matter. The tag can guide default sizing in some software.
