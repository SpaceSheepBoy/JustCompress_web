Make a 4K iPhone Video Smaller for a School Upload

Export a smaller copy, compare its file size with the portal limit and play the portion with the smallest writing or quietest speech.

Quick check

Read the assignment rules

Write down the largest allowed file size and the allowed formats. If the portal asks for MP4, choose an MP4 export. Keep the source so each attempt can start with the full-quality file.

Try it on iPhone

  1. Open the recording in Phone Cleaner: Photo & Video and choose a smaller quality preset.
  2. Compare the export size with the portal limit. Leave a little room below the limit if the portal does not explain how it calculates megabytes.
  3. Play the exported file. Pause on the smallest writing or chart label and listen to the quietest part before you upload it.

If the first copy misses the limit

Try another preset from the original, then repeat the reading and audio checks. Ask whether two clips or a link are accepted if the only copy that fits has unreadable writing.
