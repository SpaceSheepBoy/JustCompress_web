Rec.709 Export Looks Lighter in QuickTime? Check the Viewer

A Rec.709 export can look lighter in QuickTime than in an editor because their viewing pipelines may interpret gamma and display color differently. Compare the identical file under consistent conditions before changing the grade or converting it again.

Choose the approach

First isolate playback

Use one saved file, not a source preview on one side and a social-media transcode on the other. Keep display brightness and viewing conditions stable. A different appearance does not by itself prove that HDR tone mapping failed.

Try it on iPhone

  1. Confirm whether the saved file is HDR or already Rec.709 SDR. Keep the original and inspect the export’s color tags in a trusted editor.
  2. Open that same export in the editor and intended receiving player. Check the editor’s display color management and viewer gamma settings.
  3. If an HDR source genuinely needs SDR delivery, create a separate Rec.709 copy with VideoFix, then inspect that copy in the destination workflow.

A viewing mismatch is a separate problem

Adobe documents QuickTime gamma differences for Premiere exports and provides viewer-gamma choices. The correct workflow depends on your editor, display and delivery specification. Do not apply a random compensation LUT to every export or assume one appearance will match all screens.
