Focus Is On but Apps Still Open? Add an App Block

iPhone Focus can quiet alerts while still letting you open the app. If opening it is the distraction, set a separate block and test that app directly.

Check whether alerts or access are the problem

Try opening the app

Hiding a Home Screen page can reduce visible prompts, but it is a different action from restricting the selected app. Check what happens when you launch it, rather than judging only whether notifications arrive.

Test Focus and app blocking separately

  1. Keep the Focus settings that manage the calls and alerts you want. Decide separately which distracting apps should be unavailable during the session.
  2. In Dying Soon: Screen Time Limit, authorize Screen Time, select those apps and start a thirty-minute Block Now session or set an available scheduled rule.
  3. While the block is active, try opening a selected app and check that the restriction appears. Confirm that essential communication remains available. Check again when the session ends.

Two tools, two checks

Apple describes Focus as a way to manage interruptions and Screen Time as the place for app-use restrictions. You can use both, but this guide does not claim they automatically activate each other. Notification silence and blocked access each need their own check.

Use a realistic boundary

One scheduled rule and unlimited thirty-minute Block Now sessions are free; Pro adds scheduled rules. Temporary unlocks offer five, fifteen or thirty minutes.

Check other ways to open the service

The current listing does not promise a Focus automation, Mac blocking or domain-level website blocking. Another device or browser can remain a separate route to the same service. Choose a small, testable phone routine and keep the permissions and selected apps under review. Optional motivational reminders can remain off if you prefer a quiet setup.

Common questions

Does switching on Focus start a Dying Soon block automatically?

This workflow uses separate controls. Start a block or set its schedule in Dying Soon, then check access while it is active.

What if the app icon is hidden but the app still opens from search?

Hiding an icon changes what you see. Try opening the selected app during an active Screen Time block to check whether access is restricted.
