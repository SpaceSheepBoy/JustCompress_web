Why an HDR JPEG Can Look Flat in Another Viewer

An HDR JPEG can contain a normal base image plus a gain map. If a viewer ignores that map, it may show only the base image. Check the saved file on the display that matters.

Quick check

Follow the file through sharing

A messaging app may create a new copy. A viewer may handle HDR information differently. Compare the original file and the received file before assuming that the image itself is broken.

Try it on iPhone

  1. Open the same original in the viewer you plan to use. Check that the display and viewer show HDR when expected.
  2. Send a test file through your actual sharing route and open the received copy. Decide whether you need HDR for that route or a regular SDR copy for easier viewing.
  3. For a supported HDR photo, use HDR to normal photo in PhotoFix: HDR to Normal Photos to make a separate SDR copy. Check the saved copy in the destination and keep the original.

What the gain map does

A gain map gives a compatible viewer instructions for adjusting the base image according to the display’s available brightness. Viewers can handle the same file differently. The .jpg extension alone cannot tell you whether those instructions are present or used.

Choose a copy for the destination

Space Sheep Studio develops PhotoFix for iPhone. Its listing includes normal and HDR export and support for JPEG. Use the normal export when the destination needs SDR. The app does not guarantee how another viewer displays HDR or recover missing information from a shared copy.
