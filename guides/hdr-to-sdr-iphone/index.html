When an SDR copy helps

HDR footage can look washed out, too bright or different after it moves between apps and displays. That does not prove the original is broken. First compare the original in Photos with the shared copy. If the destination expects standard dynamic range, make an SDR copy for that destination and retain the HDR original for future edits.

Color conversion and file format solve different problems

HDR describes the color and brightness range. HEVC and H.264 are video codecs, while MOV and MP4 are containers. Renaming a MOV file to MP4 does not map HDR highlights to SDR. VideoFix re-encodes the footage and maps the color to Rec.709. Use the HDR checker linked below if you need to inspect a file before choosing a workflow.

Check the result before sending the whole batch

Preview skin tones, bright windows and shadows in the exported file. Compare both copies on the same display at the same brightness. Then try the actual destination. Display settings and the receiving app still affect appearance, so a successful conversion is not a promise that every screen will look identical.

Common questions

Does changing the file extension fix HDR?

No. A different filename does not change the codec or perform color mapping. Export a converted copy.

Will my HDR original disappear?

VideoFix keeps the original untouched. Check your exported SDR copy before manually deleting any original.
