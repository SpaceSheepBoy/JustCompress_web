Why Does a Video Show Bands in Smooth Skies?

Bands in a smooth sky can come from limited tonal precision, compression, the conversion pipeline or the display. Compare the original, saved export and destination player separately before blaming HDR-to-SDR conversion or buying another screen.

Choose the approach

Separate the causes

Bit depth describes how many code values can represent each channel. Eight bits provide 256 values; ten bits provide 1024. Those counts do not guarantee that a source contains smooth transitions, and a ten-bit display cannot recreate detail discarded earlier.

Try it on iPhone

  1. Play the original in a suitable player and inspect the same sky or shadow region. Keep the source untouched.
  2. If an SDR delivery is needed, make a separate copy with VideoFix: HDR Video Converter using Convert HDR to SDR.
  3. Compare the saved copy in the intended player. If bands appear only there, investigate that playback path; if they are already in the source, retain the best available original.

Tone mapping solves a different problem

Tone mapping fits brightness into the destination range. Quantization describes the spacing between representable values. They interact, but selecting Rec.709 or changing an extension does not itself ensure smooth gradients. Repeated lossy exports can also make a difficult gradient worse.
