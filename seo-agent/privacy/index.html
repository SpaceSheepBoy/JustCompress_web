Space Sheep Studio SEO

Privacy and access for our private website monitoring tool.

Effective date: October 27, 2026. Operated by Space Sheep Studio.

Private use and purpose

This desktop tool is used by the studio owner to monitor the studio’s own websites, justcompress.online and justcaptions.com. It is not a public sign-in service and does not request access from website visitors.

Google data accessed

With the owner’s explicit permission, the tool reads Google Search Console search performance, indexed URL inspection results, sitemap information and property access information. It also reads the authorizing Google account’s email address to verify the intended account. Search Console access is read-only. The collector limits website data collection to the two studio sites above.

Storage and use

OAuth credentials are stored locally outside public website repositories with restricted file permissions. Collected reports are stored in the studio’s local monitoring workspace and used to diagnose search visibility and plan improvements. Relevant reports may be processed in the studio’s Codex workspace for this purpose. Credentials are not included in reports or published on this website. Google data is not sold or used for advertising.

Retention, revocation and deletion

The owner can revoke access at any time in Google Account third-party connections. Revocation stops future API access; existing local reports can be deleted from the monitoring workspace. The owner retains reports while needed for search improvement and comparison, and can delete the local credential files to remove saved authorization.

Limited use

The tool’s use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Contact and related terms

Contact Space Sheep Studio through our support page. See the website terms and Google Account connection controls.
