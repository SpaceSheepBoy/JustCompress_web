Make one smaller sharing copy and listen to it before exporting a full recording. The useful setting depends on duration, codec and content. A format conversion alone does not guarantee a smaller or accepted file.

Listen before applying a stronger setting

Check soft speech, consonants, background noise and music at ordinary listening volume. Lossy encoding discards information; raising the bitrate later cannot recover it. If the copy sounds watery or dull, choose a less aggressive setting and compare again.

Measure the exported copy

Common questions

Will converting M4A to MP3 always shrink the file?

No. Size depends on the encoded bitrate, duration and other settings. Check the actual exported file.

Is file compression the same as dynamic compression?

No. File compression changes the encoded file size. Dynamic compression changes level differences in the audio.
