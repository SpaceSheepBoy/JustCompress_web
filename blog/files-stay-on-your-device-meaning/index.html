Modern browsers can run powerful file tools using WebAssembly and browser APIs.

  1. "Stays on your device" Work happens locally and the file is never uploaded, like Compress PDF .
  2. "Deleted after an hour" The file was uploaded; you're trusting a deletion policy.
  3. Sensitive file Prefer the first kind: no upload means there is nothing to delete.
