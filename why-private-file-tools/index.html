Three different data flows

Loading a webpage, processing a document and sharing its output are different actions. A local compressor can keep your PDF on the device while the hosting service receives ordinary connection requests. Optional website analytics can record a page visit after consent without receiving the selected file.

What to check before selecting a file

Read where processing happens, what output the tool creates and which limitations matter for your task. A server deletion promise describes uploaded files; a genuinely local operation avoids that processing upload. A private file still needs a secure device and an appropriate sharing destination.

When local processing is a practical fit

Simple compression, trimming, conversion and basic document edits can often run locally. Very large files may exceed a browser tab's resources. Keep the original, try a representative copy and inspect the result instead of assuming every supported-looking extension will work.

What local processing does not guarantee

It does not promise that a site never loads external resources, that a device is secure, or that sending the result through another service stays local. Our website privacy page explains the separate optional analytics controls.

Common questions

Does no upload mean the website is offline?

No. The page and processing software can load from the internet. A selected file can still be processed locally.

Does downloading the result share it with someone?

Saving a copy and sending it to another person are different steps. The chosen destination determines the sharing behavior.
