Quick checks

  • Keep the original file until you have opened and checked the output.
  • Try a smaller file, lower quality setting, or shorter clip if processing is slow.
  • Confirm Files or Photos permission in iOS Settings if importing does not work.
  • Restart the app if an export sheet or file picker does not appear.
