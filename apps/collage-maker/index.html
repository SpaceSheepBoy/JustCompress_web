    Everyday uses

    Different pictures. Different ways to share.

    01

    A trip in one picture

    Start with the photographs that belong together rather than every photograph from the trip. Give a favorite image more room, then use the others to add context. Move and zoom the photos so faces, landmarks and edges fit the chosen layout before saving the final image.

    Build a photo composition ↗
    02

    A clear comparison

    Use a side-by-side arrangement when the relationship between two images matters. Put the subjects in a consistent order and frame them at a useful scale. Check the final image on the screen where you will share it so the comparison remains easy to read.

    Choose a comparison layout ↗
    03

    A readable screenshot sequence

    A long image can keep selected screenshots together as one file. Arrange them in reading order, check repeated headers and inspect the joins. The composition tool does not promise automatic overlap removal. For small text, use fewer screenshots if the finished image becomes hard to read.

    Useful answers

    Before you start.

    How many photos can I combine?

    Select 2–30 photos or screenshots, then choose one of the 11 layouts.

    Can I put two photos side by side?

    Yes. Choose the side-by-side layout after selecting your images, then adjust each photo before exporting.

    Can I make a long image from screenshots?

    Yes. Choose the long-photo layout to place your selected screenshots vertically. Review the joins and framing before export.

    What file can I save?

    Export one JPEG or PNG image up to 3000 pixels wide. Save it to Photos, share it with another app, or find the finished image in Files.

    Does it add a watermark?

    The current app listing specifies no watermarks. One free export is included and every layout is available; Pro unlocks unlimited exports.

    What is the difference between Lifetime and Monthly?

    Lifetime is a one-time purchase for Pro access. Monthly is an auto-renewing subscription that continues until cancelled in your Apple Account. Check the local offer before purchasing.

    Which layout should I choose for screenshots?

    Use a long-photo layout for an ordered sequence that should be read from top to bottom. Check that small text remains readable in the final image. Review joins yourself; placing screenshots together does not necessarily remove repeated overlap.

    Which layout works best for a before-and-after pair?

    Side by side gives two images a clear comparison. Choose images that can be framed consistently, then check the crop and order before exporting. A grid is useful when you have more images to show together.

    Can I change which part of a photo appears?

    Yes. Move and zoom each photo inside its layout before export. Inspect faces, text and edges so important content stays visible. The exported file reflects the composition you chose.

    Will a grid keep every photo at its original size?

    The images are fitted into a combined composition. The output width and layout affect how many pixels each photo receives, so a large grid can make small details harder to read. Keep the originals if you need separate full-resolution files.

    Should I save JPEG or PNG?

    JPEG is often practical for photographic images; PNG is useful when you want to avoid JPEG compression around text or graphic edges. Compare the result and file size for your own images rather than assuming one format is always best.

    Can I use the app for a trip or a product comparison?

    Yes. Select the relevant images, choose a pair or grid and arrange the framing. For a trip, one larger photo can anchor the composition. For a comparison, keep similar subjects and scale together so the result is easy to read.

    Does it automatically remove overlapping screenshot content?

    The long-photo workflow places selected images into a composition. Do not assume automatic overlap removal. Check repeated headers, gaps and the order of screenshots before saving.

    How is the browser tool different from the iPhone app?

    The separate browser tool on this page offers three basic layouts for up to twelve JPG, PNG or WebP files. The iPhone app offers eleven layouts, two to thirty images and its own export allowance. The web tool does not unlock or synchronize app purchases.

    Why might the combined image be hard to read in a message?

    Messaging apps may resize or recompress large images. Inspect the saved file first, then check the received copy. For detailed screenshots, consider fewer images per composition or sharing the file through a destination that preserves the required detail.

    Can I try a layout before using my own photos?

    Yes. Load the example illustrations in the browser tool on this page, change the layout and spacing, then export a sample. These are demonstration illustrations, separate from the real app screenshots shown above.
