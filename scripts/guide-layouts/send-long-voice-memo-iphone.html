How to send a long voice memo on iPhone

A long recording will not attach? Choose a delivery method before cutting anything out.

Use AirDrop nearby, Mail Drop for a large email attachment, or a smaller audio copy when the destination has a file limit.

Share the recordingMake a smaller copy

Start in Voice Memos

Select the recording, tap More, then Share. On versions with sharing Options, choose Rendered for a single M4A file. Choose your sharing destination.

Sending to someone nearby

Choose AirDrop when both devices are available and discoverable.

Email says the attachment is too large

In Apple Mail, use Mail Drop if offered. Apple supports attachments up to 5GB; recipients have 30 days to download. This uses iCloud, so choose another route if cloud delivery is unsuitable.

Need an ordinary attachment?

Check the destination’s actual limit. Save the recording to Files, then use Audio Compressor MP3 Converter to compress a separate copy. Keep the original.

Check the new file size and listen before sending. Lower settings can reduce clarity. Ask the recipient to confirm it opens and plays.
