iPhone Video Not Playing on Windows? Start Here

If a video plays on your iPhone but not your PC, check the transfer and the player’s codec support first. Keep the original while you test a compatible copy.

Find the causeCheck the copyChoose a fix

Which check comes first?

Broken copy?

Transfer the file again if its size or duration looks incomplete.

HEVC error?

Use the appropriate Microsoft Store extension or make an H.264 copy.

Test one copy

  1. Play the original on iPhone. Keep it unchanged.
  2. Check the transferred file and read the PC’s exact error.
  3. Test a compatible copy on the same PC, including sound and the last few seconds.

For the video you already have

Microsoft says missing codecs can cause playback errors, but not every player error is a codec problem. For an HEVC file, check the official HEVC extension. Renaming .MOV to .MP4 does not change its codec.

Need a compatible copy?

On a Mac, QuickTime Player can export HEVC using Greater Compatibility (H.264). On iPhone, our VideoFix app converts HEVC to H.264 MP4 through its Convert HDR to SDR goal, including HEVC that is already SDR. Re-encoding can change quality; inspect the copy.

For future recordings

Settings → Camera → Formats → Most Compatible records new videos as H.264. It does not convert old clips. Some recording modes have separate requirements.
