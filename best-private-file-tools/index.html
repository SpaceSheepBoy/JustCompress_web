Three checks before you send

  1. Name the one operation you need.
  2. Test one file with the matching tool.
  3. Inspect the output, then decide whether a native batch workflow helps.

Open the browser tool ↗

Documents

Use Compress PDF for a smaller copy, Merge PDF for combining documents, or JPG to PDF for turning selected images into a document. Browser PDF exports include a small app logo watermark. Check readability, signatures, form fields and the recipient's requirements before sending.

Audio

Use the audio compressor for encoded file size, M4A to MP3 for that format conversion, and Trim or Split for removing or dividing sections. These are separate operations. A different extension or a shorter clip does not guarantee a particular receiving app will accept it.

Video and photos

For a short compatible clip, try the browser video compressor or MOV-to-MP4 converter. The HDR checker reads metadata; it does not convert color. Use the photo combiner for one grid or long image. Keep originals and check image quality, orientation, audio and actual file size.

When a native App is a better fit

Repeated batches and larger files may be more practical in an installed App. Our App directory lists the current published versions, full store names, real screenshots and access options. Native Apps have their own purchase terms; a free browser tool does not establish that the App is free.
